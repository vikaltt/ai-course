Превращение Word-методичек в симуляторы HTML/JS/SVG, пошаговая озвучка (Atomic Voiceover) и автономный браузерный QA.

1. Интерактив против PDF: Автономный расчетный стенд на HTML5/SVG развивает инженерную интуицию студента на порядок глубже статического чтения формул.
2. Физическая модель в коде: Расчет цепи (законы Кирхгофа, эквивалентный генератор Тевенена, векторные диаграммы) выполняется в реальном времени на чистом JS.
3. Автономный агентный QA: Агент сам открывает виртуальный браузер (Playwright), кликает переключатели, анализирует консоль на ошибки и пишет видео сессии.
4. Атомарная озвучка (Atomic Voiceover): Нарезка дорожки на короткие фразы по слайдам. Правка одного ударения требует пересинтеза 1 фразы, а не всего часа речи.
5. Страховочный трос Git: Хранение версий спасает проект при технических сбоях кода и позволяет гарантированно вернуться к рабочей точке в один клик.

⚙️ Шаблон 1: Профиль разработчика интерактивных симуляторов Вставить в Custom Instructions аккаунта
Роль: Старший разработчик интерактивных учебных симуляторов (HTML5 / Vanilla JavaScript / SVG). Кодовый регламент: 1. Никаких тяжелых сторонних библиотек: чистый JavaScript и векторная графика SVG. 2. Все физические уравнения должны быть строгими и защищенными от деления на ноль (режимы ХХ и КЗ). 3. Автономность: код обязан запускаться локально двойным кликом без необходимости веб-сервера.
🎯 Шаблон 2: ТЗ на создание виртуального лабораторного стенда Для генерации HTML-симулятора из методички
На основе текста кафедральной методички создай автономный интерактивный веб-стенд (HTML5/SVG). Требования: 1. Векторная принципиальная электрическая схема с анимацией направления токов; 2. Интерактивные ползунки регулировки параметров (R1, R2, напряжение источника); 3. Стрелочные приборы со шкалой (амперметр, вольтметр) и цифровые табло; 4. Блок автоматической проверки баланса мощностей в реальном времени.
📑 Шаблон 3: Сценарий пошаговой дикторской озвучки слайдов Для генерации аудиофайлов лекции
Подготовь дикторский текст для пошаговой озвучки 5 слайдов презентации. Правила: 1. Длина реплики на слайд — строго 60–80 слов (хронометраж ~35–45 секунд); 2. Темп академический, спокойный, интонационные паузы между ключевыми терминами; 3. Для всех аббревиатур и формул укажи фонетическую подсказку для синтезатора (например: «Э-ДЭ-ЭС», «омега-тэ»).
